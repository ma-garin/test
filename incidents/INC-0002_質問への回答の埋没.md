# INC-0002 — 質問への回答が作業報告の中に埋もれた（2026-09-29）

| 項目 | 内容 |
|---|---|
| 発生 | 2026-09-29 22:5x JST（PR #29 の作業中） |
| 発見 | 保守者「回答が長すぎて私の質問に対する回答はどこだ」 |
| 重大度 | S2（規約違反。判断材料が届かない） |
| 状態 | 対応済み（検出層は Stop hook。保守者の settings.json 登録待ち） |

## 事象

保守者の質問「OpenAI の API キーは free 版でも取得できるのか」に対し、答えの後に無関係な作業（Windows レビューの反映・commit・PR・マージ）の報告を続け、返答が約 700 字になった。質問への答えが最初の 1 行に埋もれた。

## 影響

保守者が答えを探す必要が生じ、判断が遅れた。規約「1 行目に結論、本文 3〜5 行」に違反。

## 原因

| 層 | 内容 |
|---|---|
| 直接 | 質問への返答と、並行して届いたレビュー結果の処理報告を 1 つの返答に混ぜた |
| 根本 | 「質問には答えだけを返す」を強制する仕組みが無く、私の判断に任せていた（INC-0001 と同型） |

## 再発防止（違反者の判断を経ない）

| 層 | 仕組み |
|---|---|
| 予防 | 規約: 質問には答えだけ（1 行目に結論、本文 3 行まで、400 字以内）。作業報告は別の返答か、質問者が求めたときだけ |
| 検出（独立） | Stop hook `scripts/report_gate.py`: 直前のユーザー発話が質問（？／?／〜か で終わり、作業依頼語を含まない）なら、返答が 400 字超、または 1 行目が表・見出し・箇条書き・見積で始まると exit 2 で終了を拒否 |
| 是正 | 拒否されたら答えだけに縮めるまで終われない |

## 検証（2026-09-29 23:0x JST）

該当の返答（702 字）→ exit 2。短い答え → 通過。表で始まる返答 → exit 2。作業依頼「作ってください」への長い返答 → 通過。
