# incidents — インシデント記録の置き場

| ファイル | 役割 |
|---|---|
| `LOG.md` | **インシデントログ**（記録簿）。1 件 1 行。番号・発生日時・重大度・事象・状態・報告書へのリンク。追記のみ、行は消さない |
| `INC-nnnn_<短い名前>.md` | **インシデントレポート**（報告書）。1 件 1 本。事象・影響・原因（直接／根本／副次）・過去の再検証・再発防止（予防／検出／是正）・検証・状態 |
| `TEMPLATE.md` | 報告書の雛形 |

## 運用

- 発生を認めた時点で `LOG.md` に 1 行足し（状態: 対応中）、報告書を `TEMPLATE.md` から起こす
- 再発防止は「気をつける」を書かない。**違反者の判断を経ない仕組み**（検出・拒否）を最低 1 つ入れ、動作を検証してから「対応済み」にする
- 状態: 対応中 → 対応済み（仕組みが動くことを検証した）→ 監視中（同型の再発を一定期間見る）→ 完了
- 重大度: S1 = 判断を誤らせる報告の捏造・改ざん、データ破壊 / S2 = 規約違反で成果物に誤りが残る / S3 = 軽微
