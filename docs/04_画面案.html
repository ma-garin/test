qa-sentinel 画面案

考え方は 1 つだけ。AI が下書きを作り、あなたが直して OK を押す。 OK を押すまで先に進まない。AI が何を根拠にしたかは必ず横に出る。

根拠が見えるAI の案には「仕様のどこ」「どのチェックが通ったか」が付く。根拠が無い案は OK できない
勝手に書き換えないAI は作業用の枝（ブランチ）にだけ書く。あなたの OK で本線に入る。アプリ本体は直さず「直し方の案」だけ
お金が見える使った金額と上限を常に表示。上限で止まる
誰が決めたか残るOK・差し戻し・回答は人の名前で記録。AI は「下書きを書いた人」としてしか残らない
