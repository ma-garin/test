# VeriRAG PMO Agent Design System

## 目的

品質保証・プロジェクト管理を行う人が、データの状態、判断理由、次の操作を短時間で確認できる業務画面の共通ルールです。装飾的な「AIらしさ」ではなく、ベリサーブのような落ち着いた青基調の信頼感、比較しやすさ、誤操作しにくさを優先します。

## 設計原則

1. **判断材料を先に示す。** 期限、状態、優先度、対象範囲、更新時点を、装飾より優先して表示します。
2. **青は現在地と主要操作だけに使う。** 通常文字や罫線まで青くせず、選択中・主操作・リンクに意味を絞ります。
3. **AIの出力は判断材料として扱う。** 根拠、信頼度、更新時点、最終判断者を近接して表示し、AIの結論を事実のように見せません。
4. **画面移動を途切れさせない。** 同一サイト内の遷移では画面全体を白転させず、現在の骨格を残して本文を切り替えます。遷移失敗時は通常のページ遷移に戻せることを必須とします。
5. **動きは短く、情報の変化だけに使う。** 常時動く装飾、3D、動画、派手な背景は業務フローに導入しません。OSの動き抑制設定を常に尊重します。

| 文字 | `--ink: #172033` / `--muted: #5F6E84` | 見出し・本文 / 補足 |
| ブランド | `--nav-accent: #0B4F8A` / `--blue: #0B63A3` / `--blue-soft: #EAF3FB` | 現在地 / 主要操作・リンク / 選択面 |

| 余白 | `--space-1`〜`--space-7`（4 / 8 / 12 / 16 / 20 / 24 / 30px） | 同一画面で任意の余白を増やさず、近い関係ほど狭くする |

## コンポーネント規則

### 画面骨格とナビゲーション

- 全体ヘッダー、親ナビ、子メニュー、ページヘッダー、本文の責務を混ぜません。
- 親ナビにはアイコンと名称を併記し、選択時はそのカテゴリの先頭画面を開きます。
- ページヘッダーには現在地、H1、短い目的、表示範囲、更新時点、主操作を置きます。本文とは24px以上を空けます。
- 本文だけをスクロールさせ、ページヘッダーの背後へ内容を潜らせません。

### 一覧・カード・フォーム

- 比較が目的なら表を使い、判断に必要な列だけを左から重要度順に置きます。狭い画面では表のコンテナだけを横スクロールさせます。
- 要約はカードで示しますが、カードを装飾として増やしません。1画面の主操作は原則一つです。
- フォームには入力目的、必須、エラー、保存中、成功・失敗を明示します。高影響操作には対象と影響を含む確認を置きます。

### 状態・フィードバック

- 状態は色だけに依存させず、`完了`、`ブロック中`、`期限超過` のような文字とバッジを併記します。
- 読み込み中は既存の画面を残し、ヘッダー下の短い進行線とライブ通知だけを示します。全画面ローディングやレイアウトの再生成は行いません。
- 空状態、権限不足、失敗時には、起きたことと次に取れる行動を示します。

## 画面遷移の規則

同一オリジンの通常リンクは、JavaScriptが利用できる場合に次の手順で連続遷移します。

1. 現在の画面骨格を保持したまま次画面のHTMLを取得する。
2. ナビゲーションとメイン領域を一括で差し替え、現在地、タイトル、ライブ通知を更新する。
3. 140ms以下の控えめな差し替えに留める。動き抑制時は即時に切り替える。
4. 取得に失敗した場合、通常のブラウザ遷移へ安全にフォールバックする。

未保存のフォームがある場合、遷移前に確認します。ブラウザの戻る・進む、ページャの件数切替も同じ規則を利用します。

## 参考動画の取り込み方

提示された動画「AI感のないデザインを実現するための30のアプローチ」のうち、本システムでは次を採用します。

- デザインシステムの移植: 色、余白、文字、状態、動きのトークンを共通化する。
- 順番と参照先: 既存の業務フローと参照画像を先に確認し、画面単位で新しい表現を増やさない。
- 様式と質感: 日本語の可読性を優先した書体と、控えめな罫線・淡い面で信頼感を作る。
- 動き: フィードバックに限定した短い遷移を用い、動き自体を目的にしない。

WebGL、3D、背景動画、物理演算、ジェネレーティブアートは、タスク・課題・監査といった判断中心の画面には採用しません。分析の意味を補うデータ可視化は、利用目的と読み方を定義できる場合にだけ追加します。

## 新しい画面の確認項目

- [ ] トークンを使い、画面固有の色・余白・アニメーションを増やしていない。
- [ ] 表示範囲、更新時点、状態、次の操作が画面内で確認できる。
- [ ] 主操作は一つに絞られ、破壊的・高影響操作には確認がある。
- [ ] 画面移動は白転せず、未保存データの警告と通常遷移へのフォールバックが保たれる。
- [ ] キーボードフォーカス、縮小表示、動き抑制でも操作と情報が欠けない。
