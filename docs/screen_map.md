# 画面マップと移植状況

UI の正は `docs/screens/VeriRAG_PMO_Agent_MVP.html`（モック）。
このファイルは、モックの画面と Django 実装の対応、および移植状況を管理する。

コード側の定義は `apps/core/navigation.py`。ここと食い違ったら、コードを正とする。
実行中の状況は `/core/screen-map/` でも確認できる。

凡例: **済** = 実装済み / **未** = 200 を返す未実装ページ

## AIプロジェクト管制

| 画面 | URL 名 | 状況 | 受入条件 |
|---|---|---|---|
| 管制ダッシュボード | `dashboard:control` | 済 | 選択中テナントの案件集計とアラートが表示され、案件詳細へ遷移できる |
| タスク一覧 | `dashboard:tasks` | 未 | 追加・更新・アーカイブが永続化され、フィルターとガント表示に反映される |
| 進捗予測・介入 | `dashboard:progress` | 未 | 計画実績差分から遅延見込みを示し、介入提案へ繋がる |
| 品質リアルタイム管理 | `dashboard:quality` | 未 | 消化率・不具合収束・品質ゲート合否を表示する |
| リスク予測・対策 | `dashboard:risk` | 未 | スコア・対策・状態を更新でき、案件の健康状態に反映される |
| 変更影響分析 | `dashboard:change` | 未 | 影響範囲・工数・スケジュール影響・判断状態を記録する |
| AI介入提案 | `dashboard:intervention` | 未 | 提案・根拠・判断・判断者・時刻が追跡できる。AI 不使用時も壊れない |
| KPI・効果測定 | `dashboard:kpi` | 未 | 基準値／実績／改善率を表示する |

## PMO支援

| 画面 | URL 名 | 状況 | 受入条件 |
|---|---|---|---|
| PMO相談・状況整理 | `pmo:consultation` | 済 | 意図分類、確認観点、参照根拠、根拠評価を表示し、トレースへ遷移できる |
| 計画策定 | `pmo:planning` | 未 | 計画ドラフトとレビュー観点を生成し、編集・確定できる |
| 成果物支援 | `pmo:deliverables` | 未 | AI 生成本文と確定本文を分けて保持し、赤字率を算出する |
| 報告生成・承認 | `pmo:approvals` | 未 | 下書きから承認までの状態遷移と操作履歴を保持する |
| プロンプトライブラリ | `pmo:prompt_library` | 未 | PMO タスク別テンプレートを選び、相談へ適用できる |
| 教育支援 | `pmo:education` | 未 | 新任向けの操作導線と用語解説を提供する |

|---|---|---|---|

## モックにあってナビゲーションに無いもの

以下はモックには画面があるが、現時点でナビゲーションへ載せていない。
実装するときは `apps/core/navigation.py` へ追加すること。

- タスク詳細ダイアログ（`dashboard:tasks` の一部として実装予定）
- 実データ検証（取込結果の確認画面）
- ヘルプ / まず最初に見る（`pmo:education` に統合予定）
- 体験用2案件モック（`make seed` のデモデータで代替）
