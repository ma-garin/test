# 07 使い方（初めての人向け。これだけ読めばよい）

このエージェントは **AI がテストの下書きを作り、あなたが直して OK を押す** 道具です。あなたが覚えることは 2 つ：「変更を伝える」と「自分の番のものを片づける」。

## 1. 起動（ダブルクリック 1 回）

| OS | やること |
|---|---|
| Windows | フォルダの `start.bat` をダブルクリック。初回だけ 1〜2 分待つ。ブラウザが自動で開く |
| macOS / Linux | `./start.sh` |

黒い画面が開いたままになります。閉じると止まります（それでよい）。初回は「使い方」の画面（`http://127.0.0.1:8790/guide`）が自動で開き、2 回目からは台帳の画面（`http://127.0.0.1:8790/`）が開きます。開かないときはブラウザで直接。

導入の全体は 3 ステップ: ① GitHub の Code → Download ZIP を解凍 ② そのフォルダで Codex に `docs/codex/RUN_ALL.md に従って、止まらずに最後までやれ。` を貼る（`ALL GREEN` で完成）③ `start.bat`。

## 1.5 まずデモ（図書館システム・3 分）

同梱の図書貸出システム（`demo/library-loan`）に「貸出上限を 5 冊から 3 冊に変更」を伝えて一巡します（mock なのでお金はかからない）。

| 画面（GUI） | 黒い画面（CLI） |
|---|---|
| タスクが無いときに出る **「図書館デモを動かす」** を押す | `qa-sentinel demo --by あなたの名前`（または `qa-sentinel` → 5） |
| 行をクリック → 下書きを見て **OK** | `qa-sentinel show T-0001` → `qa-sentinel ok T-0001 --by 名前` |
| 「実行」は自分でやり、結果を **渡す** | `qa-sentinel results T-0001 --by 名前 -m "全部 PASS"` |
| 報告・入替を OK → **承認** | `qa-sentinel ok …` → `qa-sentinel approve T-0001 --by 名前` |

GUI と CLI は同じ台帳 `tasks/` を見ています。

## 2. 変更を伝える（画面の一番上）

1. 「何が変わりましたか」に 1 文（例: 貸出上限を 5 冊から 3 冊に変更）
2. 「どこまで AI にやらせますか」を選ぶ。迷ったら **「準備まで AI、テスト実行は自分」**
3. あなたの名前、使ってよい金額（既定 $5）
4. 「始める」

AI が下書きを進め、止まる点で「やることリスト」に出ます。AI が待っている間はお金がかかりません。

## 3. 自分の番を片づける（やることリストの上から）

| 表示 | あなたがすること |
|---|---|
| あなた: 直して OK | AI の下書き（テストの表）を見て、直したい所を直して **OK**。納得できなければ **差し戻す**（理由を書く） |
| あなた: 自分でやる | AI が用意した手順で自分がテストし、できた／できなかったと見たままを入れて **渡す** |
| あなた: 質問に答える | AI が仕様に無いことで止まっています。答えを書いて **回答** |
| あなた: 最終承認 | 全部終わりました。名前を入れて **承認** |
| 止まった | 理由を読む（予算超過・3 回差し戻し・質問 5 件など）。進め方を変えて始め直す |

OK・回答・承認は必ずあなたの名前で記録されます。AI は承認欄を埋めません。

タスクの詳細の進行表示はスイムレーン工程図です（AI／あなた／システムの 3 レーン。今どの段が誰の番かが分かる）。画面は PC 専用で、ページはスクロールしません。

## 4. 黒い画面が好きな人

`qa-sentinel` と打つだけで番号メニューが出ます（1 始める／2 やることリスト／3 ブラウザ／4 一覧／5 図書館デモ）。コマンド名を覚える必要はありません。

## 5. 今できること・できないこと

| できる（鍵なし・mock） | 鍵を入れるとできる（本番） |
|---|---|
| 段取り・画面・止まる点・記録・ループ上限（差し戻し 3／質問 5／セッション 10）の全部 | AI が実際に下書きする（Managed Agents）。予算は金額で上限が効く |
| 図書館デモでの一巡。入替段で CSV を実際に書き換える（`config.toml` の `apply_swap = true` のとき） | 影響分析・ケース表・実行手順が本物になる |

鍵を入れる手順（4 行。鍵はファイルに書かない）:

```bat
venv\Scripts\pip install -e .[managed]
set ANTHROPIC_API_KEY=sk-ant-...
venv\Scripts\python -m qa_sentinel.agent.register --project library-loan
set QA_SENTINEL_RUNTIME=managed && start.bat
```

`GITHUB_TOKEN` があればリポジトリも AI に渡ります（無くても動く）。あなたのプロジェクトは `projects/_template` を写して `env.md` を埋める。

## 6. 困ったら

| 症状 | 対処 |
|---|---|
| `start.bat` で「Python 3.11 以上を入れてください」 | python.org から 3.11 以上を入れて、もう一度 |
| 画面が開かない | ブラウザで `http://127.0.0.1:8790/` |
| 「env.md がない」 | プロジェクトの環境情報が未記入。`projects/<名前>/env.md` を埋める |
| ずっと「AI が作業中」 | mock では起きない。本番で起きたら黒い画面を閉じて起動し直す（台帳は残る） |
