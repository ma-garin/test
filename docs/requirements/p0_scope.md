## P0（最初に動かす範囲）

### 1. 案件選択と管制ダッシュボード

**受入条件**: 案件の状態、進捗、オープンリスク、AI 提案、重要アラートを一画面で確認でき、
指標やアラートから詳細へ移動できる。

| 項目 | 状況 |
|---|---|
| 案件の集計表示（課題・リスク・ブロック・提案の件数） | 実装済み |
| 重要アラートの一覧 | 実装済み |
| 案件詳細への遷移 | 実装済み |
| アラートからタスク・リスク詳細への遷移 | 実装済み |
| 案件選択 | 実装済み（`accounts:select_project`。全画面に効く） |

### 2. WBS／タスク管理

**受入条件**: 追加・更新・アーカイブが永続化され、フィルターとガント表示に反映される。

| 項目 | 状況 |
|---|---|
| データモデル（担当・期限・進捗・優先度・次アクション・ボール保持者・PMO フォロー状態・関連タスク・根拠メモ） | 実装済み |
| 一覧・検索・絞込み | 実装済み |
| 追加・編集・アーカイブ画面 | 実装済み |
| ガント表示 | 実装済み |
| マイルストーンの予実差分析 | 実装済み（登録は Django admin のみ。`open_questions.md` OQ-010） |
| 入力ルールの遵守状況 | 実装済み（担当・期限・Blocked運用・週次更新・進捗整合） |

### 3. リスク・課題・変更の管理

**受入条件**: 影響度・確率・対策・状態・期限を管理でき、案件の健康状態に反映される。

| 項目 | 状況 |
|---|---|
| データモデル（Risk / Issue / ChangeRequest） | 実装済み |
| 変更要求の影響範囲・工数・スケジュール影響・判断状態 | 実装済み |
| 一覧・編集画面 | 実装済み |
| 健康状態（HealthSnapshot）への反映 | 実装済み（`dashboard/services/overview.py`） |
| 案件単位の権限による書き込み制御 | 実装済み（`projects/permissions.py`） |

### 4. AI介入提案と人の判断

**受入条件**: 提案ごとに対象・根拠・推奨アクション・判断者・判断理由・状態が残り、
採用／修正／却下／承認を区別できる。

| 項目 | 状況 |
|---|---|
| データモデル（`InterventionProposal`） | 実装済み |
| 採用／修正して採用／不採用／実施済みの区別 | 実装済み |
| `AgentRun` / `EvidenceEvaluation` / `HumanReview` によるトレース | 実装済み |
| 提案の生成ロジック | 実装済み（検知結果から自動生成） |
| 提案一覧・判断画面 | 実装済み |

### 5. RAGの文書登録・検索・チャット

**受入条件**: 登録状態、検索結果、引用根拠、不明時の案内を表示できる。

| 項目 | 状況 |
|---|---|
| 登録前の検証（形式・サイズ・空・重複） | 実装済み |
| 文書台帳の表示、再インデックス要否 | 実装済み |
| ハイブリッド検索（ベクトル + 語彙 + RRF） | 実装済み |
| 引用根拠とスコア内訳の表示 | 実装済み |
| 未登録・ゼロ件の案内 | 実装済み |
| アップロード画面 | 実装済み |
| 本文抽出（PDF/Office → DocumentPage） | 実装済み |
| RAG チャット | 実装済み（案件の状況を文脈として付与） |
| 回答生成 | **未実装**。設計を ADR-0004 として提案済み、判断待ち |
