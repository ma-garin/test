# 要件トレーサビリティ

出典: `docs/reference/mvp_scope_directory_mapping.csv`（55項目）と
`docs/reference/directory_extra_features.csv`（21項目）。

**この表が完了判定の分母である。** `apps/core/navigation.py` の `status` は
「画面が動くか」であって「要件を満たすか」ではない。実装側の申告を充足判定に使わない。

経緯は `docs/INCIDENT-001-scope-omission.md` を参照。

凡例:

- **済** … 実データで動作し、受入条件を満たす
- **部分** … 動くが、要件の一部が欠けている（欠けている内容を備考に書く）
- **未** … 実装が無い
- **対象外** … 参考データ側で対象外と明記されている
