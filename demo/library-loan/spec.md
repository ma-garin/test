# spec — library-loan（社内図書館 貸出管理）

## 目的
Excel で管理している社内図書館の貸出台帳を Web 化し、貸出・返却・延滞確認を図書係がブラウザで行えるようにする。

## 対象ユーザー
- 図書係（総務部）: 貸出・返却の記録、延滞の確認と連絡
- 利用者（社員）: 本実装で検討（モックは図書係のみ）

## FR（モックの範囲）
| ID | 要件 | 検証基準（モック） |
|---|---|---|
| FR-1 | 蔵書の一覧・検索・状態（貸出可 / 貸出中 / 延滞）の表示 | 検索語と状態フィルタで絞り込め、0 件は空状態が出る |
| FR-2 | 貸出の記録（利用者・返却期限） | モーダルで記録され、上限超過はフィールド直下にエラー |
| FR-3 | 返却の記録 | 確認ダイアログ → 記録 → トースト |
| FR-4 | 延滞・返却期限の可視化 | ダッシュボードの KPI とコールアウト、期限順の一覧 |
| FR-5 | 貸出中一覧の CSV 書き出し | ダウンロードされる |
| FR-6 | Excel 台帳の取り込み | **未実装**（UI のみ） |

## NFR
- 単一 HTML・外部 CDN なし（社内配布・オフライン可）
- 360px / 1366×768 / 1920×1080 で崩れない。ライト・ダーク両対応
- 操作には必ず結果を返す（成功トースト・消えない失敗＋次の行動・処理中・空状態・確認）
