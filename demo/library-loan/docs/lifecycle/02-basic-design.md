# 基本設計書（外部設計） — 社内図書館 貸出管理

> 上位: `01-requirements.md`／下位: `03-detailed-design.md`
> **全 `REQ-F` を1つ以上の `BD` に割り当てる**（未割り当てゼロが出口基準）。

**日付**: 2026-09-29 ／ **状態**: ドラフト

## 全体構成

```text
利用者 → Web 画面 → 各サービス（認証・検索・貸出・返却・通知） → 台帳 DB
                                                       ↘ 社内メール
```

## 構成要素（BD）

| ID | 要素 | 種別 | 責務（1行） | 対応 REQ |
|---|---|---|---|---|
| BD-001 | 認証 | モジュール | ID とパスワードで利用者を認証し、未認証を遮断する | REQ-F-001, REQ-N-002 |
| BD-002 | 貸出上限判定 | モジュール | 貸出前に貸出中の冊数を数え、上限 5 冊で拒否する | REQ-F-003 |
| BD-003 | 蔵書検索 | 画面 | 検索語で蔵書と貸出状態を表示する | REQ-F-002, REQ-N-001 |
| BD-004 | 返却処理 | モジュール | 返却を記録し、蔵書を貸出可に戻す | REQ-F-004 |
| BD-005 | 返却期限通知 | モジュール | 期限前日に貸出中の利用者へメールを送る | REQ-F-005 |

## 画面設計（該当する場合）

- 画面は ログイン / 蔵書検索 / 貸出 / 返却 の 4 つ。視覚仕様はデザインシステムに従い、値をここに書かない

## データモデル

| エンティティ | キー | 主要項目 | 保存先 | version |
|---|---|---|---|---|
| 蔵書 | 蔵書番号 | タイトル・著者・貸出状態 | SQLite | 1 |
| 貸出 | 貸出番号 | 利用者・蔵書番号・返却期限・返却日 | SQLite | 1 |

- スキーマ変更時のマイグレーション方針: version を上げ、起動時に変換する
- export / import の対象範囲: 貸出中一覧の CSV 書き出しのみ

## 外部インターフェース

| 相手 | 方式 | 入力 | 出力 | 失敗時の挙動 |
|---|---|---|---|---|
| 社内メールサーバ | SMTP | 宛先・件名・本文 | 送信結果 | 3 回再送し、失敗を運用ログに残す |

## 非機能要件の実現方式

| # | 対象 REQ-N | 実現方式 | 検証方法（ST で使う） |
|---|---|---|---|
| 1 | REQ-N-001 | 書名・著者に索引を張る | 蔵書 1 万件で応答時間を測る |
| 2 | REQ-N-002 | フォーカス順とコントラストを部品側で保証 | キーボードのみで一巡する |

## 技術選定

| 論点 | 候補 | 採用 | 理由 |
|---|---|---|---|
| 保存先 | SQLite / PostgreSQL | SQLite | 小規模で運用が軽い |

## リスクと回避策

|---|---|---|
| 上限値の変更 | 判定が食い違う | 上限は設定値 1 か所に置く |
