### RFD-001 貸出台帳を Excel から Web システムへ移す

#### 背景・課題
Excel の貸出台帳を手作業で更新しており、貸出上限（1 人 5 冊）の超過と返却期限の見落としが起きている。

#### 影響範囲
対象は図書係と利用者（社員）、対象システムは社内図書館の貸出管理。人事・購買システムとの連携は触らない。

#### 選択肢

| # | 案 | 利点 | 欠点 | コスト（工数/運用） |
|---|---|---|---|---|
| A | 社内 Web システム化 | 上限判定と通知を自動化できる | 開発と運用が要る | 中 |
| B | Excel にマクロを足す | 早い | 同時編集に弱い | 小 |
| C | 何もしない | 費用ゼロ | 超過・見落としが続く | 0 |

#### 決定
- 採用: A。上限判定・返却・期限通知をシステムで担保する
- 却下理由: B は同時編集で台帳が壊れる。C は課題が残る

#### スコープ外
Excel 台帳の取り込み、外部蔵書 DB との連携。
