### DD-001 AuthService.login

| 項目 | 内容 |
|---|---|
| 対応 BD | BD-001 |
| 対象ファイル | `src/auth_service.py` |
| 種別 | 関数 |

#### 入出力

| 区分 | 名前 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| 入力 | id, password | str | ○ | 利用者 ID と平文パスワード |
| 出力 | session | Session | | 成功時のみ |

#### 処理手順

1. 入力の空を検査する
2. ID でハッシュ済みパスワードを引き照合する

- 事後条件: 失敗時にセッションは発行されない

| 条件 | 検知方法 | 挙動 | 利用者への表示 |
|---|---|---|---|
| ID かパスワードが不一致 | 照合結果 | 拒否 | 「ID かパスワードが違います」 |

#### 境界値

| 項目 | 下限 | 上限 | 0件/空 | 備考 |
|---|---|---|---|---|
| 入力長 | 1 | 64 | 空は拒否 | |

### DD-004 LoanService.canBorrow の上限判定

| 項目 | 内容 |
|---|---|
| 対応 BD | BD-002 |
| 対象ファイル | `src/loan_service.py` |
| 種別 | 関数 |

#### 入出力

| 区分 | 名前 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| 入力 | user_id | int | ○ | 利用者 |
| 出力 | ok | bool | | 貸出できるか |
| 出力 | reason | str | | 拒否理由 |

#### 処理手順

1. 利用者の未返却の貸出を数える
2. 現行上限（5 冊）と比べる
3. 5 冊以上なら拒否し、理由に上限 5 冊を入れる

#### 事前条件 / 事後条件

- 事前条件: 利用者が存在する。事後条件: 記録は変えない（判定のみ）

#### 異常系

| 条件 | 検知方法 | 挙動 | 利用者への表示 |
|---|---|---|---|
| 利用者が存在しない | 検索結果 | 例外 | 「利用者が見つかりません」 |
| 上限超過 | 冊数 >= 5 | 拒否 | 「貸出上限 5 冊に達しています」 |

#### 境界値

| 項目 | 下限 | 上限 | 0件/空 | 備考 |
|---|---|---|---|---|
| 貸出中冊数 | 0 | 5（4 冊は可・5 冊で拒否） | 0 冊は可 | 上限は設定値 |
