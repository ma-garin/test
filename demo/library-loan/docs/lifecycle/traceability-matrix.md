## 記入規則

- 1セルに複数 ID を書く場合はカンマ区切りで併記する（下の UT 列を参照）
- 該当しないセルは `-` を入れる。**空欄はカバー漏れとして検出される**
- `REQ-F` は **UAT 列必須**、`REQ-N` は **ST 列必須**（V字の対応）
- 状態: `未着手 / 実装中 / 検証中 / 合格 / 保留`
- 各表の1行目は記入例。実 ID に置き換える。`-0xx` の行は未採番のプレースホルダで、採番するまで検査対象外
- 版つきリンク（任意）: セルの ID を `REQ-F-001@a1b2c3d` と書くと、その行の下流を「上流の版 a1b2c3d で確認した」記録になる。上流の定義（見出しの節、表で定義した ID はその行）が変わると `trace-check.sh` が suspect（C7）として NG にする。`@` の無いリンクは従来どおり
  - 版は手で書かない。**保守者が**下流を見直したうえで `./scripts/trace-check.sh docs/lifecycle --refresh REQ-F-001` を打つと記入・更新される（AI は打たない）。上流を変える前の影響確認は `--impact REQ-F-001`
