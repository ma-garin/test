# 事例: 社内図書館の貸出管理を Excel から Web へ（HTML モック）

キットの「使い方」を通しで見せるための実例。**依頼文は 1 行**:

> 社内図書館の貸出管理を Excel から Web システムにする。HTML でモックを作ってください

この 1 行から、キットの規律（目的 1 行・残課題・未検証）と手順書（single-html-tool / design-system / uiux_review / done-gate）だけで、ここにある `library-loan.html` ができた。ハンズオンの教材でもある（`01_利用者向け資料/01_利用ガイド.html` の「ハンズオン」章）。

## 中身

| ファイル | 何か |
|---|---|
| `library-loan.html` | **完成したモック**（単一 HTML。ダブルクリックで開く。データはブラウザ内 localStorage） |
| `app.css` / `app.js` | モック固有のソース（配置 20 行の CSS と、画面ロジック）。部品・骨格はキットの実物を使い、書き足していない |
| `build.py` | `app.css` / `app.js` とキットの実物（tokens.css / ui/components.css / ui/layout.css / components/icons.js / feedback.js）から `library-loan.html` を組み立てる。**HTML を直接編集しない** |
| `spec.md` | 依頼文から起こした仕様（FR-1〜FR-6・NFR）。`sdd-ecc-workflow` の形 |
| `CURRENT_STATE.md` | 引き継ぎメモ（フェーズ・次のタスク・判断待ち・未検証） |

## 開く・作り直す・検査する

```bash
open 01_利用者向け資料/90_サンプル/図書貸出/library-loan.html          # モックを見る（Windows は start、Linux は xdg-open）
python3 01_利用者向け資料/90_サンプル/図書貸出/build.py                 # キットの部品を更新したら再生成
./00_導入/03_点検/check-design.sh 01_利用者向け資料/90_サンプル/図書貸出        # 直値・未定義トークン・CDN・alert() の検査（NG=0 が合格）
```

## この事例で確認できたこと（2026-09-17）

- 5 画面（ダッシュボード / 蔵書 / 貸出中 / 利用者 / 設定）が、キットの CSS を**貼るだけ**で揃った。書き足した CSS は配置の 20 行
- 操作には必ず結果が返る: 貸出（モーダル・冊数上限のエラー）／返却（確認 → 記録 → トースト）／失敗（消えないメッセージ＋「もう一度」）／0 件（空状態とボタン）／処理中
- 360×820 / 1366×768 / 1920×1080・ライト／ダークで横スクロールなし（Playwright で 14 状態を確認）
- **キット自身の欠陥が 3 件見つかり、是正した**（`06_保守者向け/01_内部仕様/09_指摘事項.md` F-14〜F-16、`06_保守者向け/学んだこと.md`）。事例で通しでやると、部品のセルフテストでは出ない問題が出る

## モックの範囲外（本実装で対応）

Excel 台帳の取り込み（UI のみ）／利用者の追加・編集／認証／サーバ保存（localStorage は端末間で共有されない）／本物の通信失敗（設定画面のトグルで再現しているだけ）
