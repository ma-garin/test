qa-sentinel の使い方 AI がテストの下書きを作り、あなたが直して OK を押す道具

この画面は起動時に自動で開きます。台帳の画面は こちら。

1. 導入（3 ステップ）

1zip を取るGitHub の Code → Download ZIP を解凍。Windows 11・Python 3.11 以上だけあればよい（git・bash は不要）
2Codex に 1 文解凍したフォルダで cmd を開き Codex（gpt-6-sol, high）を起動して貼る:
docs/codex/RUN_ALL.md に従って、止まらずに最後までやれ。OS は Windows 11、シェルは cmd、git は無い。
終わると scripts\verify.py の末尾が ALL GREEN
3start.bat をダブルクリック初回だけ 1〜2 分。ブラウザにこの画面と台帳の画面が開く。閉じたいときは黒い画面を閉じる（macOS/Linux は ./start.sh）

2. まずデモ（図書館システム・3 分）

同梱の図書貸出システム（demo/library-loan）に「貸出上限を 5 冊から 3 冊に変更」という変更を伝え、AI が計画〜準備を下書きし、あなたが直して OK し、実行はあなたがやり、最後に承認するまでを通します。mock なのでお金はかかりません。

画面（GUI）黒い画面（CLI）
台帳の画面の 「図書館デモを動かす」 を押す（タスクが無いときに出ます）qa-sentinel demo --by あなたの名前
または qa-sentinel → 5
やることリストの行をクリック → 下書きを見て OKqa-sentinel show T-0001 → qa-sentinel ok T-0001 --by 名前
「実行」はあなたの番。結果を書いて 渡すqa-sentinel results T-0001 --by 名前 -m "全部 PASS"
報告・入替を OK → 承認qa-sentinel ok … → qa-sentinel approve T-0001 --by 名前

GUI と CLI は同じ台帳（tasks/）を見ています。片方で進めた結果はもう片方にも出ます。

3. 自分のプロジェクトで使う

やることどこで
環境情報を書く（URL・起動手順・削除禁止・触ってよいソース）projects/_template を写して projects/<名前>/env.md を埋める
変更を 1 文で伝え、4 つの質問に答える（どこまで AI／どこで止まる／だれが見る／いくらまで）画面の「変更を伝えて始める」／qa-sentinel run --project <名前> --nl "…"
自分の番を片づける（直して OK・自分でやって渡す・質問に答える・承認）やることリスト／qa-sentinel のメニュー 2
本物の AI で動かす（鍵を入れる）pip install -e .[managed] → set ANTHROPIC_API_KEY=… → python -m qa_sentinel.agent.register --project <名前>（1 回）→ set QA_SENTINEL_RUNTIME=managed で start.bat。詳しくは 07 §5

守られること: AI は作業ブランチにしか書かない。製品コードは案を出すだけ。予算は画面に出て上限で止まる。OK・回答・承認はあなたの名前で記録され、AI は承認欄を埋めない。
